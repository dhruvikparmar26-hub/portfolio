## 📌 Overview

A modern, high-performance developer portfolio showcasing full-stack engineering architectures, AI-augmented systems, and algorithmic problem-solving. Designed with an editorial dark-mode aesthetic, custom typography, fluid interactions, and real-time 3D computation.

---

## ✨ Key Features

- **Interactive 3D Neural Sphere**: Real-time holographic neural lattice, crystalline core, and floating quantum particle swarm rendered with Three.js and dynamic mouse parallax.
- **Curated Engineering Projects**: Detailed breakdowns of production-style full-stack systems:
  - **Momentum**: Personalized Learning Management System with RBAC and event-driven Socket.io.
  - **Journeys**: AI Travel Planner with LangGraph multi-agent orchestration and SSE streaming.
  - **VisionCaption**: PyTorch ViT + GPT-2 Image Captioning pipeline with attention maps.
- **Interactive Tech Stack**: Categorized skill pills covering Languages, Frameworks, Databases & Tools (Docker, REST APIs, MongoDB, WebSockets), and Core CS Pillars.
- **Editorial Typography & UX**: Responsive layout built with React 19, Motion micro-interactions, and bespoke styling.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dhruvikparmar26-hub/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
